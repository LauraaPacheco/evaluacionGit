# evaluacionGit

Taller práctico de control de versiones con Git y GitHub — Ingeniería de Software III (UNIAJC).

Proyecto de microservicios para una EPS (Entidad Promotora de Salud), organizado en tres ramas con contenido diferente.

## Ramas

| Rama | Contenido |
|---|---|
| `main` | Estructura base: `eps-microservicios/` y `EstructuraMicroservicios_EPS.docx` |
| `desarrollo` | Base + `Docs/` (arquitectura de microservicios) + `Algoritmos_pruebas/` |
| `pruebas` | Base + `Algoritmos_pruebas/` |

## Microservicios

api-gateway · autenticacion · afiliaciones · citas-medicas · historia-clinica · autorizaciones · facturacion · notificaciones
